What's shipped in each Ledgerly desktop release. The app checks for updates automatically once installed (Settings → Check for Updates).

v0.1.7 Aug 13, 2026
Latest

Fixed Google sign-in

"Continue with Google" was silently broken in every released installer since it launched — the desktop build was missing its OAuth credentials. Fixed the release process so Google sign-in now works in the packaged app on both Windows and Mac.

New accounts now require an 8-character minimum password, and login/signup are rate-limited against automated attempts. Also added behind-the-scenes error monitoring and reliability improvements, plus routine dependency updates.

Smarter notification behavior

OS-level notifications now only pop up while the app window is closed or minimized — the in-app notification bell keeps updating live either way, so you're not double-notified while you're already looking at the app.
